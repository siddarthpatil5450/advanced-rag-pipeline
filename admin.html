Only needed once per browser session below. Set on the server with $env:RAG_ADMIN_KEY before starting it.

What happens when you upload

1. The file is saved into the project folder.
2. Text is extracted (OCR runs automatically for scanned pages).
3. It's split into chunks and embedded into the vector database.
4. Your local model writes a short summary of what it covers, for the search index.

This can take a few minutes for large or scanned documents — leave this tab open. Re-uploading a file with the same name replaces the old version (use this for quarterly contract refreshes).
